# Greek Mythology Cultural Data Collection

## Overview

This project is a cultural data collection application focused on Ancient Greek mythology.

The application allows users to enter information about Greek mythology stories, including the title of the myth, its main figure or character, and its main theme or cultural meaning.

## Files

- `cli_data_entry.py` — Python command-line interface for collecting Greek mythology data.
- `index.html` — HTML interface that collects the same cultural data through a web browser.
- `greek_mythology_data.json` — Sample structured data produced by the Python application.
- `requirements.txt` — Python dependency required to run the CLI application.
- `ai-chat-log.md` — Documentation of AI assistance used during development.
