# The Labyrinth of Greek Mythology

## Theme

This maze explores Ancient Greek mythology and the role that myths played within Greek society.

## How to Start

Begin in the `entrance` directory.

Use the command line to explore the maze and read the clues.

Useful commands:

- `pwd`
- `ls`
- `ls -la`
- `cd`
- `cat`

Not every path leads to the solution.

## Goal

Follow the clues and find the final destination.

Think about not only what the myths are about, but also what they meant to the people and society that told them.
